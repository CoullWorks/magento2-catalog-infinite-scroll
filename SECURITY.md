# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Email **ttechitsolutions@gmail.com** with:

- a description of the issue and its impact,
- the module version and Magento version,
- steps to reproduce (a proof of concept if possible).

You'll get an acknowledgement within a few working days, and a fix or mitigation
plan once the report is confirmed. Responsible disclosure is appreciated and
credited in the release notes if you'd like.

## Supported versions

Fixes land on the latest `2.x` release. Older majors are not maintained.
