# Catalog Infinite Scroll for Magento 2 documentation

Online version: <https://www.coullworks.com/docs/magento/infinite-scroll>

## Pages

- [Overview](overview.md): What Catalog Infinite Scroll does, where it works, what it needs, and how it protects Core Web Vitals. A free, MIT licensed module for Luma themes.
- [Install](install.md): Add the module with Composer or by copying it, run the Magento setup commands, flush the cache and check it. Needs Magento 2.4.7 to 2.4.9 and PHP 8.2 to 8.5.
- [Get started](get-started.md): Enable the module, test it on a category and check the address bar, View More and analytics behave. No code needed.
- [Configure](configure.md): Every admin setting of Catalog Infinite Scroll, field by field, with the allowed values, default, scope, what it changes on the storefront and a screenshot.
- [Per store view](store-views.md): Turn infinite scroll off, or change any setting, for one store view or website without touching the others.
- [The widget](widget.md): Add infinite scroll to any list on a CMS page, static block, Page Builder or layout XML. Every widget parameter explained, with screenshots.
- [How it behaves](behaviour.md): Auto scroll versus View More and the 768 px rule, the URL becoming ?p=N, Back and Forward, the end of the list, where it attaches and search results.
- [Layout modes](layout-modes.md): Default theme grid, Masonry, Isotope and Packery, when each loads its library and how to choose.
- [Reference](reference.md): The init payload and every JS option, events, analytics, CSS hooks, templates, accessibility, bundled libraries and what the module does not install.
- [Troubleshooting](troubleshooting.md): Fix the common problems: nothing loads, the pager still shows, items overlap, the button is missing, Back loses pages, analytics double counts.
- [Upgrade](upgrade.md): Update to a new release with Composer, and what changed when moving from the BoxLeaf module, from 2.0.x to 2.1, or from 2.1.0 to 2.1.1.
- [Changelog](changelog.md): Release history for the Catalog Infinite Scroll module for Magento 2, newest first, with what changed in each version.
